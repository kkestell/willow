# Parser review

## Scope and coverage

Reviewed the staged Parser changes against `agents/plans/2026-10-14-003-parser.md`, `willow.md` §3 and §5, and `AGENTS.md`: `compiler/parser.lua`, `tests/unit/parser_test.lua`, and `agents/todo.md`. Also read the code the parser depends on or feeds (`compiler/lexer.lua`, `compiler/ast.lua`, `compiler/diag.lua`, `compiler/span.lua`, `compiler/cli.lua`, `tests/run.lua`). Bind, check, lower, and emit are stubs, so valid files end in an internal compiler error at bind; how those passes consume the tree is outside this review. Checks ran on macOS only.

Beyond the plan, a statement whose first token cannot start an expression raises `expected a statement, found <token>` before expression parsing, so a stray `else` or an over-indented line gets that message.

## Fixed

- **Unclosed parenthesis at end of file reports `found dedent`** (`compiler/lexer.lua:238`): a missing `)` on the last line of a function body produced `expected ',' or ')', found dedent`, because the lexer emitted the closing DEDENTs before EOF even inside open parentheses. The same mistake at file scope already reported `found end of file`. The lexer now emits no DEDENTs at EOF while parentheses are open; such a file never parses, so valid programs are unaffected. Added `unclosed_parenthesis_at_end_of_file` to `tests/unit/parser_test.lua`.

No open findings.

## Checks run

- `make test`: `33 passed, 0 failed`, exit 0 (32 before the fix).
- Scratch probes of `parser.parse(lexer.lex(...))` on: unclosed parentheses at EOF with and without a final newline, an empty block before a following `def`, stray `else` and `elif`, `while`/`else`, an over-indented line, `(x) = 1`, `f(), g()`, conditional expressions, `def for()`, `return)`, `(a == b) == c`, `not a == b == c`, `int(x)` as a statement, a multiline call with a trailing comma, stray `)` at file scope and in a body, empty and comment-only files, `is not`, `not in`, `elif` without a condition, `return 1, 2`, and `-(1)(2)`. Each produced the plan's tree or a diagnostic at the expected token.
- `./willow check` on a comparison chain: `chain.wlo:2:16: error: comparison chains are not supported`, exit 1. `./willow run` on an unclosed call: `unclosed.wlo:3:1: error: expected ',' or ')', found end of file`, exit 1. `./willow check examples/*.wlo`: both reach `bind not implemented`.
- Timing: a 858 KB, 4,000-function file parses from 344,001 tokens in 0.04 s.

## Verdict

The parser matches the plan and the spec, and the tests cover the planned cases. One diagnostic issue fixed; no open findings. Ready to commit.

Two departures from the plan are intended: bind sorts functions and records by source position before checking names, so the later declaration of a clashing pair is the one reported; and duplicate parameter and field checks share `check_unique`. The review fix below also replaces the plan's parenthesized `Field` emission with a temporary.

## Fixed

- **Field access on a constructor call emits invalid Lua** (`compiler/lower.lua:232`): `P(1, 2).x = 3` after a call statement emitted `({ x = 1, y = 2 }).x = 3` on the next line, which LuaJIT rejects with `ambiguous syntax (function call x new statement)`, so `willow run` and `willow build` failed with an internal compiler error on a valid program. `lower_object` now moves a constructor used as a field's object into a temporary for both field reads and field assignments, and `Field` emission no longer parenthesizes its object. Added a constructor-object read and write to `tests/programs/records.wlo`.

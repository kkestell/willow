## Fixed

- **Unreadable file reaches the compiler as nil source** (`compiler/cli.lua:44`): `io.open` succeeds on a directory, but `file:read("*a")` returns nil. `willow check examples` passed nil to the lexer, which would surface as an internal compiler error once the lexer exists, where the plan requires `error: <io message>` and exit 1. The CLI now checks the read result and prints `error: <path>: <message>`.

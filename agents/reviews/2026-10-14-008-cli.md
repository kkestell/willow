# CLI review

## Scope and coverage

Reviewed the staged CLI changes against `agents/plans/2026-10-14-008-cli.md`, `willow.md` §8, and `AGENTS.md`: `compiler/cli.lua`, `tests/unit/cli_test.lua`, and `agents/todo.md`. Also read the launcher, `tests/run.lua`, and the `emit.emit` contract the CLI depends on.

The `ffi` `stat` declarations were run on every platform the plan names except old glibc: macOS arm64 natively, macOS x86-64 (a cross-built LuaJIT under Rosetta, which resolves `stat$INODE64`), Linux arm64 and x86-64 on glibc 2.36, and Linux x86-64 on musl 1.2.5. On all five, the full suite passes and the C `struct stat` offsets match the declared `dev` and `ino` fields. Linux x86-64 ran under Docker emulation. 32-bit platforms were not checked.

## Fixed

- **`build` crashes on glibc older than 2.33** (`compiler/cli.lua:80`): before glibc 2.33, `libc.so` exports only `__xstat`, not `stat`, so `willow build` exited 1 with an uncaught `undefined symbol: stat` traceback on Debian 11, Ubuntu 20.04, and RHEL 8. Willow does not support glibc older than 2.33: `README.md` now states that Linux needs glibc 2.33 or newer, or musl, and the CLI keeps its single `stat` declaration.

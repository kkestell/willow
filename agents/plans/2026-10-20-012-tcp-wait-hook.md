# TCP wait hook

## Goal

Prepare the TCP runtime for async TCP. The four blocking TCP operations in
`runtime/host.lua` (`net.connect`, `recv`, `sendall`, and `Listener.accept`)
wait through `__wlo_wait_fd`. A later slice adds `aio` operations with `net`'s
semantics that wait by suspending the current task, so the waiting has to be
replaceable without changing what `net` does.

## Related code

- `runtime/host.lua`: `__wlo_wait_fd`, `__wlo_net_connect`,
  `__wlo_net_connection_recv`, `__wlo_net_connection_sendall`,
  `__wlo_net_listener_accept`.
- `agents/reviews/2026-10-20-009-async-spec.md` and the "Async TCP" items in
  `agents/todo.md`.
- `tests/programs/sockets.wlo` exercises all four waits, including timeouts.

## Decisions

- Each operation's body takes its wait function first:
  `__wlo_socket_connect(wait, host, port, timeout, site)`, and the same shape
  for `recv`, `sendall`, and `accept`. The wait keeps `__wlo_wait_fd`'s
  contract: `wait(fd, events, deadline)`, true when the fd is ready and false
  on the deadline.
- The `net` helpers keep their exact signatures and behavior by passing
  `__wlo_wait_fd`. Programs and tests are unaffected.
- The shared bodies are declared like the other helpers, so they are exported
  as `__wlo_runtime.socket_*` and `runtime/aio.lua` can pass a suspending wait
  to them. Nothing about `aio` itself is added here.

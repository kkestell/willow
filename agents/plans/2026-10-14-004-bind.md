# Bind

## Goal

Replace the `compiler/bind.lua` stub with name resolution for willow.md §6 and
§7. `bind.bind(program)` collects every function signature, checks the entry
point, gives each function's parameters and assigned names one symbol each for
the whole body, and annotates the tree in place with resolved symbols and call
targets. It raises one diagnostic through `diag.error` at the first binding
error. After this change `willow check` and `willow run` report binding errors
and reach the check stub for valid files.

## Related code

- `compiler/bind.lua` — stub to replace; keeps `M.bind(program)`.
- `compiler/parser.lua` — node shapes: `Program { functions }`,
  `Function { name, params, return_type, body }`, `Param { name, type }`,
  `Assign { name, annotation, value }`, `CallStmt { call }`, `Return { value }`,
  `If { condition, body, else_body }`, `While { condition, body }`,
  `Name { name }`, `Call { name, args }`, `Unary { operand }`,
  `Binary { left, right }`. Spans are the identifying token: the name for
  `Function`, `Param`, `Assign`, `Name`, and `Call`; `Program` is at 1:1.
- `tests/unit/parser_test.lua` — helper style (`eq`, error capture) to follow.

## Decisions

- **Symbols.** A symbol is a plain table `{ name, span, param }`. `span` is the
  declaring `Param` or the first `Assign` in source order, and `param` is `true`
  for parameters. Each function has one symbol per local name, and table identity
  is the symbol's identity. Later passes attach facts to it, for example the
  checker's type.
- **Annotations added to the tree.**
  - `Param.symbol`, `Assign.symbol`, and `Name.symbol` point at the symbol.
  - `Function.locals` lists the non-parameter symbols in order of first
    assignment, for declaring them at function entry.
  - `Call.target` is the called `Function` node or the shared built-in
    descriptor `{ kind = "Builtin", name = "print" }`. Later passes branch on
    `target.kind`.
- **Order of work.**
  1. Collect signatures: map function names to `Function` nodes. The second
     definition of a name raises `duplicate function '<name>'`. A function named
     `print` raises `cannot redefine built-in function 'print'`. A repeated
     parameter name raises `duplicate parameter '<name>'`.
  2. Check the entry point. No `main` raises `program has no main function` at
     the `Program` span. A `main` with parameters or a return type other than
     `None` raises `main must take no parameters and return None` at its span.
  3. Bind each function body in file order, in two walks. The first creates
     symbols for parameters, then for every `Assign` name in source order,
     descending into `if`, `else`, and `while` bodies. The second resolves
     names, so a call or read before a name's first assignment already sees the
     local.
- **Resolving names.**
  - A `Call` whose name is a local or parameter raises
    `cannot call local variable '<name>'`. Otherwise it resolves to a file-level
    function, then to `print`; anything else raises
    `unknown function '<name>'`.
  - A `Name` resolves to a local or parameter. A function or `print` name used
    as a value raises `function '<name>' cannot be used as a value`; anything
    else raises `unknown name '<name>'`.
  - Arguments and operands are resolved left to right, so the first error in
    source order is reported.
- **First error only.** Bind stops at its first error, like the lexer and
  parser.

## Test plan

`tests/unit/bind_test.lua` runs `lexer.lex`, `parser.parse`, then `bind.bind`.
Helpers: `eq`, `bind_source(source)` returning the bound program, and
`bind_error(source)` returning `"line:col: message"` and failing the test on
success or a non-diagnostic error.

- `signatures_collected_before_bodies`: `main` calls a later function, and two
  functions call each other; each `Call.target` is the right `Function` node.
- `duplicate_names_rejected`: a duplicate function, a duplicate parameter, and a
  function named `print`.
- `main_required`: no `main`, `main` with a parameter, and `main` returning
  `int`.
- `locals_cover_the_whole_body`: a name assigned in both `if` branches and read
  after them shares one symbol across both `Assign` nodes and the `Name`. A
  reassigned parameter keeps the parameter's symbol, with `param` set.
  `Function.locals` holds only the non-parameter local.
- `locals_shadow_functions_and_print`: assigning to names `g` and `print` in a
  function makes them locals, and reads of them resolve to those symbols.
- `cannot_call_local_variable`: calling `print` before a later
  `print = ...`, calling a parameter, and calling a local that shadows a
  function.
- `unknown_names_rejected`: an unknown name and an unknown function.
- `functions_are_not_values`: a function name and `print` used as values.
- `call_targets_recorded`: `print` resolves to the built-in descriptor, and a
  call nested in arguments and operands is resolved too.
